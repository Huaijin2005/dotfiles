# 导师背调分析 Skill

请你作为一名"科研规划顾问 + 导师尽调分析师"，帮我全面评估【@大学 @老师】是否适合作为我读研的导师。

我希望你尽量基于公开可查的真实信息进行分析（如：Google Scholar、DBLP、导师主页、实验室主页、学校官网、基金项目、学生论文署名、公开采访、学生去向、论坛/社交平台公开评价等），不要泛泛而谈，而要像"做导师尽调"一样给出有判断力的结论。

---

# 一、评估目标

请回答核心问题：

1. 这位老师是否值得去？
2. 适合什么类型的学生？
3. 风险点在哪里？
4. 如果我目标是"科研产出 / 顺利毕业 / 读博 / 就业"，他分别是否合适？

---

# 二、请按以下维度系统分析

## 1. 学术实力（重点看"真实科研战斗力"，不是只看头衔）

请分析近5年的情况，尽量量化：

### 1）论文产出质量与稳定性
- 近5年论文总量
- 高质量论文数量（CCF-A / 中科院一区 / Nature/Science子刊 / 顶会顶刊）
- 是否持续稳定产出，还是某几年集中爆发、后续转弱
- 研究方向是否前沿，是否还在活跃推进，还是已有"过气/断更"迹象
- 是否有代表性成果，学术影响力如何

### 2）署名结构与真实贡献度

请特别分析：
- 老师本人在近年论文中的**一作占比**
- 老师作为**通讯作者/最后作者**的占比
- 是否更多是"挂名合作"还是明显在主导方向
- 是否存在大量论文但老师本人主导痕迹不强的情况
- 是否存在"论文多但主要靠合作方输出"的迹象

### 3）研究方向与培养门槛
- 方向是否偏理论 / 偏工程 / 偏交叉 / 偏应用
- 对学生背景要求高不高（数学、编程、实验能力、英文写作）
- 学生进入后能否较快上手，还是需要很强基础才能跟上

---

## 2. 资源与平台

### 1）学校与平台
- 【所在学校】在该方向上的平台水平如何
- 导师所在学院/实验室资源是否强
- 是否有重点实验室、研究院、交叉平台支持

### 2）项目与经费
- 是否有国家级项目（NSFC、重点研发、重大项目等）
- 是否有持续项目支持，说明经费比较稳定
- 是否承担较多横向/企业合作项目
- 经费和项目是否有利于学生做出成果，而不是只做杂活

### 3）合作网络
- 是否与其他高校/研究院/企业有稳定合作
- 合作层级高不高（是否能接触更强团队、更好资源）
- 学生是否有机会参与联合培养、实习、合作发表

---

## 3. 学生培养情况（重点）

请尽量通过学生论文署名、毕业去向、公开信息进行判断，不要只说"未知"。

### 1）学生论文产出情况

请重点看：
- 是否有学生以**一作**身份发表论文
- 学生一作论文数量是否稳定，不只是个别尖子生
- 学生是否能发到较好的会议/期刊，还是多数只有低水平成果
- 导师论文里学生名字是否经常出现，还是导师/合作方占主导
- 是否存在"老师高产，但学生一作很少"的情况

### 2）培养上限与下限

请特别判断：
- 学生在**研二/研三达到毕业要求后，是否仍继续发论文**
  - 如果是，说明导师可能有更强科研训练能力，能把学生往更高水平推
  - 如果达到毕业指标后普遍停产，可能说明培养上限一般，或实验室目标偏"毕业即可"
- 学生是否只是"够毕业"，还是能做到"读博/冲更高平台"
- 是否有学生进入更好的高校读博 / 去大厂 / 去高校 / 去研究院

### 3）毕业与去向
- 学生毕业是否顺利
- 是否有明显读博去向
- 就业去向如何（大厂、研究院、高校、普通就业）
- 去向是否稳定，还是个体差异极大

### 4）导师带学生的方式

请尽量判断：
- 是亲自带，还是主要靠博士/高年级学生带
- 是高压推进型，还是放养型
- 是偏"论文导向"，还是偏"项目导向"
- 是否有成熟培养路径（新生→跟项目→发论文→毕业）

---

## 4. 导师风格与风险评估（重点中的重点）

请尽量基于公开信息、学生反馈、讨论区信息、经验帖等，进行"谨慎但有判断力"的分析。

### 1）负面信息与争议

请主动搜索并分析是否存在：
- 压榨、PUA、情绪化管理
- 拖延毕业
- 过度占用私人时间
- 画饼、承诺资源但实际不给
- 学生劳动成果归属不清
- 对学生署名不公平
- 导师长期失联、甩手掌柜、挂名导师
- 明显负面新闻、学术争议、舆情风险

若没有明确证据，也请说明：
- "未发现公开负面信息"
- 但是否存在某些间接风险信号（如学生流动异常、成果结构异常等）

### 2）实验室氛围

请判断实验室更像哪一种：
- 高压卷王型
- 强科研训练型
- 项目打工型
- 自由放养型
- 温和但产出一般型

并解释依据。

### 3）隐性风险信号

请特别留意并分析这些"高风险特征"：
- 论文很多，但学生一作比例低
- 导师本人署名强势，学生成长弱
- 学生到研三还主要做低价值杂活
- 论文多集中于少数学生，其余人存在感低
- 经费项目很多，但学生成果与去向一般
- 近几年产出看起来高，但核心成果依赖合作单位
- 方向跨度过大，可能导致培养不聚焦
- 导师行政事务过多，可能无暇带学生

---

## 5. 我与该导师的匹配度分析

请从"适合谁 / 不适合谁"的角度分析，而不是笼统地下结论。

请分别判断这位导师适不适合以下类型学生：
- 想稳毕业，不追求顶会
- 想冲论文，最好硕士期间发高水平成果
- 想继续读博
- 想找高质量实习/就业
- 基础一般，但愿意努力
- 基础强，想追求高上限
- 不喜欢高压环境的人
- 需要导师高频指导的人
- 更适合被放养、自驱力强的人

并请分析我和他的匹配度，尤其从以下角度：
- 方向匹配度
- 难度匹配度
- 性价比
- 风险收益比

---

# 三、输出格式要求

请务必按以下结构输出：

## 1）总评结论

只给一个明确结论：
- 强烈推荐
- 推荐
- 谨慎考虑
- 不太推荐
- 不推荐

## 2）核心理由（3~5条）

必须是最关键、最有判断力的点，不要空话。

## 3）详细分析

按"学术实力 / 资源平台 / 学生培养 / 风格风险 / 匹配度"展开。

## 4）证据与依据

- 请列出你的判断主要依据来自哪里
- 哪些是公开硬信息，哪些是基于信息结构做出的合理推断
- 如果有信息缺口，请明确指出，不要假装确定

## 5）风险清单

请单独列一个"风险清单"，按严重程度排序。

## 6）适合报考建议

请告诉我：
- 适合把他放在"冲 / 稳 / 保"哪一档
- 如果不推荐，我更应该找什么类型的导师替代（例如：年轻高产型、项目资源型、稳毕业型、强指导型、读博导向型）

---

# 四、分析原则（务必遵守）

1. 不要只看头衔和学校名气，要看真实带学生能力。
2. 不要只看论文总量，要看近5年趋势、质量、署名结构、学生受益情况。
3. 不要默认"高产导师 = 适合学生"，要区分"导师强"和"学生能否受益"。
4. 对"负面评价"要谨慎，不轻信单条匿名信息，但如果多处出现相似反馈，要作为风险信号。
5. 如果缺少直接学生反馈，请通过论文署名、学生去向、成果持续性、实验室信息进行间接判断。
6. 结论必须明确，不要模棱两可。
7. 宁可承认信息不足，也不要泛泛吹捧。
